
# Patient Risk Stratification Using Machine Learning

An academic machine learning project that uses health indicators
to estimate the probability that a record belongs to the
diabetes-positive class.

## Model
- Random Forest Classifier
- Scikit-learn
- Streamlit interface

## Features
- Collects health indicator inputs
- Estimates class-1 probability
- Displays an experimental risk category

## Important Disclaimer
This is an academic demonstration, not a clinically validated
diagnostic or screening tool. Predictions must not be used as
medical advice or to make healthcare decisions.

## Run Locally
Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```
